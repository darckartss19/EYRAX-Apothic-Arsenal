# EYRAX Apothic Arsenal 0.3.0

Contenido preparado para publicar en GitHub:

- `EYRAX-Apothic-Arsenal-0.3.0.jar`: addon para NeoForge 1.21.1.
- `EYRAX-Apothic-Arsenal-0.3.0-Resource-Pack.zip`: paquete opcional de cliente que deja el tooltip normal de Simply Swords.
- `SHA256SUMS.txt`: hashes de los archivos descargables.
- `CHANGELOG.md`: cambios de esta versión.

Instala el JAR en `mods` y conserva Apotheosis, Simply Swords y Simply Tooltips. Retira el JAR 0.2.0 y desactiva los perfiles de recursos 1.0/1.1 anteriores si los tenías instalados.

El cambio de página del tooltip normal se hace con la rueda del mouse o con `G` cuando el contenido es suficientemente largo.
